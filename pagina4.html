  • Dominio:

    en HTML, el término "dominio" se refiere al nombre de dominio de un sitio web, no a un elemento HTML en sí mismo.

  • Sub Dominio

    Un subdominio es una extensión del dominio principal que permite crear subsecciones dentro de un sitio web.

  • URL

    Una URL, o Localizador de Recursos Uniforme (Uniform Resource Locator), es la dirección web que identifica y localiza un recurso específico en la web, como una página, una imagen o un archivo

  • DNS

    DNS, o Sistema de Nombres de Dominio, es como la guía telefónica de internet.

  • Hosting

    El hosting, o alojamiento web, es un servicio que permite almacenar y publicar los archivos de un sitio web en internet

  • FTP

    FTP, que significa File Transfer Protocol o Protocolo de Transferencia de Archivos, es un protocolo de red que permite la transferencia de archivos entre sistemas en una red, especialmente Internet

  • HTTP

    HTTP, que significa Hypertext Transfer Protocol (Protocolo de Transferencia de Hipertexto), es el protocolo de comunicación que se utiliza para transferir información a través de la World Wide Web

  • URL

    Una URL, o Localizador de Recursos Uniforme (Uniform Resource Locator), es la dirección web que identifica y localiza un recurso específico en la web, como una página, una imagen o un archivo

  • HTTPS

    HTTPS, que significa "Hypertext Transfer Protocol Secure", es la versión segura del protocolo HTTP, que es el protocolo principal para enviar datos entre un navegador web y un sitio web.

  • W3C

    En informática, W3C (World Wide Web Consortium) es una organización internacional que desarrolla estándares y directrices para la World Wide Web.

  • UTF-8

    n informática, UTF-8 es un sistema de codificación de caracteres que permite representar textos de diferentes idiomas, incluyendo caracteres que no están en el conjunto ASCII.

  • HTML 5 y Estructura

    HTML5 es la última versión del Lenguaje de Marcado de Hipertexto (HTML), que se utiliza para estructurar y presentar contenido en la web. En computación, la estructura en HTML5 se refiere a la organización jerárquica de los elementos que componen una página web, como encabezados, párrafos, listas, imágenes, etc.
